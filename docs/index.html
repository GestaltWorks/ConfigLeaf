What this page is. A replay of recorded, redacted real collections taken on 24 Oct 2026 from two production Linux hosts (nginx, over SSH with a fixed script of reads; the key is the operator's, so the read-only property is the script's) and six Cloudflare DNS zones with their audit log. Every name, address, host and actor is a pseudonym keyed by the tenant's salt, and every value hash an HMAC under it; the salt is withheld, so a guess at a real name cannot be confirmed against this page. Nothing is authored: each example is a slice of sample/bundle.json cut by scripts/examples.ts, and each finding is what the pass (src/pipeline.ts) computed over its slice with no model.

How it was built. npm run site binds every check's parameters from its finding the way the pass does, renders the catalogue template through the data layer on sql.js, and once more with each table read as its Zetaris semantic-layer entity (lightning.metastore.drift.drift_usl.<entity>) as the text a live pass sends, shown under each query; it runs the sql.js text again over the slice and refuses to publish unless the row count, the verdict and the sentence equal the record; the detector query must return the finding's own row. It also refuses on any template it cannot render, and on any string that matches the operator's deny-list or that the redactor would still replace. A table shows at most 20 rows and 240 characters per cell; the row count and the row hash cover every row and every character. The Document and Sources tabs are markdown turned into HTML at build time, every character outside headings, paragraphs, lists, tables, inline code and bold escaped: examples/document.md as npm run document wrote it, and the section sourcesMarkdown() reads off the SQL; the deny-list scan reads both as written. The Nemotron tab is static HTML from one eval results directory, the newest under eval/results unless --results names another: the build loads the recording and the policy rows its runs name into sql.js, re-guards and re-runs every judge SELECT recorded with a row count, and refuses to publish when one that runs returns another count; every string the tab is built from passes the deny-list scan and the redactor.

Reproduce it. In a clone of the repository, with nothing but Node 22 and npm install: SAMPLE_MODE=true npm run sample reproduces the findings from the repo (the full bundle, no credentials, no model); npm run examples recuts these slices and recomputes their findings; npm run site rebuilds this page.
