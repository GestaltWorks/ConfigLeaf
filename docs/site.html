ConfigLeaf, package drift-agent, is a configuration assurance agent for an MSP.

The eight places

the live host (over SSH)
the nightly export (the backup tarball)
the documentation of record (approved_setting, the rows an IT Glue or Hudu adapter would write)
the DNS provider (Cloudflare)
the provider's audit log and each host's journal
the asset inventory
what the site answers from outside (the probes)
the PSA (the tickets)

Zetaris USL (drift_usl)

DRIFT, LESSONS, RULES fourteen entities, five DQ rules
Entities: collection, setting, referent, backup_copy, policy, copy, probe, disposition, action, ticket, cause, lesson, rule, adoption
DQ rules: run_complete on collection, copy_validated on copy, action_verified on action, cause_evidenced on cause, exception_in_force on adoption
