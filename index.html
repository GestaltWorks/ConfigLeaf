ConfigLeaf

One setting lives in eight places. ConfigLeaf reads all eight as one, and decides what to do.

A configuration assurance agent for MSPs, running on a real estate. It checks every finding with SQL through Zetaris, has Nemotron try to prove the finding wrong, and decides under the MSP's own policy. Every model call comes back with a signed receipt.

Every call carries a signed receipt: 390 calls, 384 receipts published and verified offline, no substitutions, no injected memory.

How a pass works

Rules decide. Models only read and refute.

  1. Read all eight

    The live host, the backup, the documentation, DNS, the audit log, the inventory, the probes and the tickets, joined in one Zetaris semantic layer. A run that read less than it promised is thrown out.

  2. Check with SQL

    Detectors join across sources. A catalogue of checks tests each finding. A setting whose bytes match the backup but whose DNS name now points elsewhere only shows in the join.

  3. Try to refute

    Nemotron Lightning picks the checks. Nemotron Ultra writes one SELECT that returns rows only if the claim is false. A verdict counts only on a verified receipt.

  4. Decide and explain

    Policy and the technician's earlier lessons give one verb: ROLLBACK, FIX, ESCALATE, HOLD with an expiry, or ADOPT. One ledger row each, with who changed it and when.

Real, not a mock-up

  • It runs on the operator's two production hosts, six Cloudflare zones and the mail records of a Microsoft 365 tenant.
  • On 25 Oct 2026 a staged DNS change on production was raised as a byte-identical setting whose referent changed, named, and put back through the provider.
  • A live pass sends 235 queries through Zetaris in about 48 seconds and decides 27 findings under the MSP's policy.
  • Writes happen only behind --apply; every query is SELECT-only; a Scout guard blocks injected instructions before a model reads them.
  • Sample mode replays a redacted recording of the same estate, with no credentials and no model, so anyone can run the real pass.

Run it in two minutes

Node 22 or later. No credentials, no .env.

npm ci
SAMPLE_MODE=true npm run sample      # the whole pass, about 5 seconds
SAMPLE_MODE=true npm run console     # the technician's console on http://127.0.0.1:8090/

The console is a local app: every setting with its lock, and the technician's Unlock, Approve and Lock.
